# 공개 문서 목차

이 폴더는 ZUKU의 **공개 저장소에서 확인할 수 있는 계약**을 설명합니다. 전체
개발자 입구는
[조직 개발 문서](https://github.com/zukuapp/.github/blob/main/docs/README.md)입니다.
파일 형식, 필드, 호출 방법은 각 저장소의 최신 명세가 기준입니다.

| 읽을 문서                                  | 확인할 것                       |
| ------------------------------------------ | ------------------------------- |
| [플랫폼 개요](00-overview.md)              | 공개 제품과 저장소의 역할       |
| [공개 아키텍처](01-architecture.md)        | ZWF2와 ZWF1의 형식·실행 경계    |
| [공개 작업 방식](02-project-management.md) | 명세 변경과 기여 절차           |
| [데이터 모델](05-database.md)              | OpenAPI 모델과 저장 계층의 구분 |
| [API 안내](06-api.md)                      | 명세의 경로·인증·페이지네이션   |
| [브랜드 안내](07-frontend-design.md)       | Trecillo 로고, 서체, ZUKU 색상  |
| [배포·운영 문서의 범위](08-deployment.md)  | CI와 공개 운영 정보의 한계      |

이 문서들은 비공개 인프라 설정, 내부 데이터베이스 스키마, 서비스 배포 상태를
공개하지 않습니다. 이전 자료에 있던 일정과 운영 구성은 검증 가능한 현재 상태로
취급하지 않습니다.
