# 브랜드와 문서 디자인 / Documentation brand

플랫폼의 공식 이름은 **ZUKU**입니다. 회사명 **Trecillo**와 기존 저작권·
라이선스는 보존합니다.

[한국어·영어 로고 안내](branding/README.md)는 승인된 PNG 원본, 테마 선택,
SHA-256과 공식 슬로건을 기록합니다. 이전 SVG나 개발자 배너를 현행 ZUKU
로고로 재사용하거나 새 로고를 생성하지 않습니다.

The official platform name is **ZUKU**. Preserve the legal operator Trecillo
and existing notices and licenses. The [Korean and English logo guide](branding/README.md)
records the approved PNG bytes, theme selection, checksums, and official slogan.
Do not use legacy SVGs or banners as the current logo or generate a new logo.

## 서체와 색상 / Typography and colors

README의 본문은 GitHub 글꼴을 사용하고 제목·링크·설명은 텍스트로 유지합니다.
제품 색상은 SWIPE `#FFD600`, JUMP `#EC008C`, HYPE `#00BCF2`입니다.
색상 토큰을 바꾸더라도 승인된 로고 원본을 다시 칠하지 않습니다.

GitHub supplies README body fonts. Keep headings, links, and descriptions
as text. Product colors do not authorize recoloring the approved logo.
