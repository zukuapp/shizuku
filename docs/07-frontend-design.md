# Frontend Design & Brand Guide

## Brand Identity

- **Name**: Shizuku (abbr. zuku)
- **Domain**: zuzunza.com
- **Logo**: Droplet shape with neon green accent

## Color Palette

| Role       | Hex       | Usage         |
|------------|-----------|---------------|
| Background | #0A0A0F   | Main bg       |
| Surface    | #141420   | Card/surface  |
| Primary    | #00FFC8   | Neon green    |
| Secondary  | #FF00AA   | Pink accent   |
| Accent     | #FFD600   | Yellow accent |
| Text       | #EAEAEA   | Body text     |

## Typography

- **Korean**: Pretendard
- **Latin**: Inter
- **Monospace**: JetBrains Mono (code)

## Responsive Breakpoints

| Viewport  | Width        | Layout      |
|-----------|--------------|-------------|
| Mobile    | ~767px       | Single col  |
| Tablet    | 768-1023px   | 2 columns   |
| Desktop   | 1024px+      | 3+ columns  |
