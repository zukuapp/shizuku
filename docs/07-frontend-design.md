# 브랜드와 문서 디자인

사용자에게 표시하는 플랫폼 이름은 **ZUKU(즈쿠)**, 회사 이름은
**Trecillo(트레실로)**입니다. `Shizuku`는 저장소 이름과 이전 자료에 남은
프로젝트명입니다. 현행 시각 기준은
[Trecillo 사이트](https://trecillo.crevision.kr/)와
[조직 브랜드 문서](https://github.com/zukuapp/.github/blob/main/docs/brand.md)에서
확인합니다.

## 로고

현재 개발자 허브는
[Trecillo 사이트의 로고 원본](https://trecillo.crevision.kr/assets/brand/game-ci.png?v=20260919)을
사용합니다.
[조직 저장소의 사본](https://github.com/zukuapp/.github/blob/main/profile/assets/brand/trecillo-game-ci-20260919.png)과
[개발자 배너](https://github.com/zukuapp/.github/blob/main/profile/assets/developer-hero.png)도
같은 원본을 따릅니다. 로고의 비율, 글자, 배경색을 임의로 다시 그리지 마세요.

이 저장소의 `assets/zuku-logo*.svg`는 이전 디자인의 파일입니다. 새 문서의
Trecillo 로고로 사용하지 않습니다.

## 서체와 색상

현행 Trecillo 웹 기준은 한글 본문에 **Pretendard**, 영문 표시 문구에 **Inter**를
사용합니다. 한글 대체 글꼴로 Noto Sans KR을 둡니다. GitHub README의 본문 글꼴은
작성자가 지정할 수 없으므로 문구는 텍스트로 유지하고, 고정 서체가 필요한
배너에서만 이미지로 표현합니다.

| 용도                 | 색상      |
| -------------------- | --------- |
| Trecillo 로고의 분홍 | `#FF2D7A` |
| 문서용 어두운 배경   | `#0B0C10` |
| ZUKU Hype            | `#00BCF2` |
| ZUKU Swipe           | `#FFD600` |
| ZUKU Jump            | `#EC008C` |

위 제품 색상은 Hype·Swipe·Jump를 구분하는 보조 표식입니다. 로고 자체의 색상을
바꾸는 근거로 사용하지 마세요. 세부 토큰과 자산 갱신 절차는
[조직 브랜드 문서](https://github.com/zukuapp/.github/blob/main/docs/brand.md)를
따릅니다.
